# Security Policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for **Tairitsua/Tairitsua.Monica.GachaPool**. Include the affected version, a minimal reproduction, impact, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

Only the latest prerelease or stable package line is supported with security fixes.
